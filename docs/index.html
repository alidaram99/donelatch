DoneLatch refuses acceptance of a coding agent’s “done” until fresh checks pass and detect a configured behavioral fault.

Run the demo first

Clone the reviewed release. The demo runs in a disposable copy and leaves its shipped source unchanged.

git clone --branch v0.1.1 --depth 1 https://github.com/alidaram99/donelatch.git
cd donelatch
npm ci
npm run demo

Use it in your project

Initialize and edit the template to define your actual result and a meaningful negative control.

npx --yes github:alidaram99/donelatch#v0.1.1 init
# Review and configure receipts.yml before running commands.
npx --yes github:alidaram99/donelatch#v0.1.1 run
npx --yes github:alidaram99/donelatch#v0.1.1 faultcheck
npx --yes github:alidaram99/donelatch#v0.1.1 verify-done

Install the Gemini CLI extension

gemini extensions install https://github.com/alidaram99/donelatch --ref v0.1.1

Know what the receipt means

Hooks request correction; they are cooperative guardrails. A host can stop an UNVERIFIED turn after the retry cap. The CLI still refuses acceptance. Temporary copies are not a sandbox, and a signature from your own local key is not independent review.

The guarantee covers your configured watched scope and declared faults. It does not cover excluded files, malicious same-user processes, or every user requirement. Read the security boundaries.

Why this problem matters

In Stack Overflow’s 2025 developer survey, 66% of respondents to the AI-frustrations question reported almost-correct solutions. That motivates verification; it does not establish a failure rate for this tool or any individual agent. Primary survey source.

DoneLatch complements Stryker’s broader mutation analysis, Checkly’s production monitoring, and ordinary CI. Its focus is a small outcome contract connected to current completion evidence.

Common questions

How do I check a coding agent’s done claim?

Configure an acceptance assertion and meaningful fault in receipts.yml, run DoneLatch run and faultcheck after the last edit, then use verify-done. It accepts only matching current evidence.

Does DoneLatch hard-block Claude Code, Codex or Cursor?

Hooks are cooperative guardrails, with at most one corrective turn and an UNVERIFIED warning afterward. Hosts can still stop. Use verify-done in a separately controlled acceptance step when its nonzero exit must be enforced.

Does DoneLatch upload code or charge per check?

Version 0.1.1 is local, MIT-licensed and free, with no telemetry or hosted service. Configured project commands can independently use the network.

Can green tests still miss bugs?

Yes. The included demo removes a persisted write: a weak return-value check stays green while a fresh reader catches the defect. A configured negative control covers that particular outcome, not all possible defects.
